Технические требования

1) Общая функциональность и структура

Страница должна содержать минимально следующие секции (в виде отдельных семантических блоков):

    -Header (с логотипом/именем и навигацией по разделам);
    -About / О себе (несколько абзацев или список достижений);
    -Skills / Навыки (список / карточки с процентами или уровнями);
    -Portfolio / Примеры работ (3–6 карточек с изображениями и описанием). Если работ как таковых нет, приложите лабы, которыми гордитесь 😎;
    -Contacts / Контакты (email, телефон, ссылки на соцсети);
    -Footer (копирайт, ссылки).

Страница должна быть одностраничной с anchor-переходами.

2) Верстка и адаптивность

    Обязательное использование Flexbox или Grid для основных макетов (не делать всё через абсолютные позиции).
    Адаптивность: предусмотреть как минимум 3 точки перелома:
        -Mobile — ширина ≤ 767px;
        -Tablet — 768px–1023px;
        -Desktop — ≥ 1024px.
    Для каждого брейкпоинта дизайн должен оставаться читабельным и функциональным (меню, карточки, изображения перестраиваются логично).

3) Организация кода / файловая структура

Пример рекомендуемой структуры репозитория:

lab1-portfolio/                <-- репозиторий
├─ index.html
├─ css/
│  └─ styles.css
├─ images/
│  └─ ...
├─ README.md
└─ .gitignore

4) Git / GitVerse / GitHub /

Требуется:

    Создать публичный репозиторий на GitVerse / GitHub.
    README.md должен содержать краткое описание проекта, ФИО и группу автора, ссылку на деплой (если есть).

Коммиты должны быть осмысленными (пример: init: add project structure,
feat: add header and hero section,
style: add responsive layout for mobile).
