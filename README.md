Технические требования

1) Общая функциональность и структура

Расширить проект Лабораторной работы №1 (сайт-визитка), добавив динамическое поведение с использованием jQuery. Страница должна включать следующие элементы:

    Выпадающее меню (при клике отображается/скрывается список навигации).
    Форма обратной связи (на странице или на модальном окне).
    Симуляция работы отправки формы через $.ajax()
    Хотя бы одно модальное окно (закрывается по крестику/оверлею).
    Динамическая галерея (Portfolio):
        Данные о работах загружаются из внешнего JSON-файла (portfolio.json) через
        $.getJSON или
        $.ajax.
        Галерея рендерится динамически (генерация карточек через jQuery).
    Простая анимация — например, плавное появление элементов или скролл к секции.
    Валидация полей ввода/форм (например, email и обязательные поля в форме обратной связи).
    Карусель навыков или изображений:
        Слайдер в секции «Навыки» или «Портфолио».
        Кнопки «Предыдущий» и «Следующий» для навигации.
        Автоматическое пролистывание каждые несколько секунд.
    Подсветка активного пункта меню при скролле.
    Кнопка «Вверх» — плавный скролл к началу страницы.
